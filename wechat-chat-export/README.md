# 微信聊天记录导出（wechat-chat-export）

把 Windows 微信 4.x 本地数据库里的聊天记录解密并导出，生成可浏览的 HTML 时间线、CSV、TXT 三种格式——方便喂给 AI 分析，或做留底归档。

由 **天工创新坊** 开发维护，许可 **CC BY 4.0**（署名即可自由使用、修改、分发）。

## 有什么用处？

- 把和某个人（单聊/群聊）的聊天记录完整导出，交给 AI 分析（沟通复盘、谈判留底、关系梳理等）
- 生成微信风格的可浏览网页时间线，按天翻看；同时给 CSV/TXT 便于搜索和归档
- 附验证跑通的四步工作流和踩坑记录：确定数据目录 → 捕获数据库密钥 → 解密导出 → 核对结果，配好现成脚本

## 为什么要用？

微信聊天记录存在加密数据库里，AI 读不到，人也难一键导出。手动复制太累，截图喂 AI 又烧额度；更麻烦的是错误路线（内存扫描、反复重启微信）浪费大量时间。本技能把一条已验证的正确路线整理成四步，帮你一次走对。

## 如何用？

1. 本技能是为 WorkBuddy 等智能体（Agent）准备的：安装到智能体的技能目录后，直接说"导出我和 XX 的微信聊天记录"，智能体会按技能四步流程执行
2. 前置条件：Windows 系统、微信已登录过（数据目录在磁盘上）、Python 依赖 `pycryptodome` 和 `zstandard`（`pip install pycryptodome zstandard`）
3. 首次捕获密钥需要微信运行并登录，接受一次"重启微信 + 手机确认登录"；若本机没有密钥捕获组件，脚本会自动联网获取所需的第三方工具（一次性）
4. 导出本身不要求微信正在运行（有密钥 + 离线主库即可）

## 有问题怎么办？

- 不同账号目录要用不同的数据库密钥，某把密钥只能解锁一个账号目录——导错账号时先确认目录再重新捕获密钥
- 密钥捕获失败 → 确认微信正在运行且已登录，按 SKILL.md 的步骤重来一次
- 导出记录不完整 → 检查是否选对了消息主库文件，详见 SKILL.md 踩坑记录
- ⚠️ 仅限导出**本人登录的账号**的聊天记录，用于个人备份与分析；请勿用于侵犯他人隐私或违反法律与微信用户协议的用途，由此产生的后果由使用者自负
